## 一句话

监测工具让你看见自己不在答案里。我们让工厂每周把能被引用的一页、能被抄到的一个源做完，并用同一批海外采购问句证明做没做。

不是又一个 AI 可见度看板。是出口工厂的每周获客操作系统：眼睛负责证明，手负责把本周三处和该进的第三方源做完、确认、复测、接到询盘线索。

## 卖谁 / 不卖谁

卖：有英文站或在建英文站的出口工厂；品类靠规格、认证、工况成交；买得起每周执行、能让技术改三处；赛珀客户经理驻场。工厂老板看英文周报。

## 界面必须能证明

| 差异 | 别人 | 我们 |
| --- | --- | --- |
| 工作单元 | 提及率 / SOV | 工单：补丁 → 确认已发布 → 同一问复测，过/不过 |
| 事实层 | 通用改写 | 没有 Fact Pack（已批英文 + 官网）不能出对外草稿 |

## 问句

每个市场用人录的固定采购问句。来源是销售 / 询盘 / 展会 / 客户自己说的原句，或经理手录的采购题。禁止模型编题。没有问句就空着。

抽查默认海外引擎单独报。国内引擎另账。DeepSeek 只写草稿，不算海外可见度。
